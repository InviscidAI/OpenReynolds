# Tests the pre-commit hook deselects, and why.
#
# One node id per line; `#` and blank lines are comments. `scripts/precommit_tests.py`
# deselects these from the suite it runs, and then runs exactly this list again on its
# own, with no deselect, so a line that has started passing is reported at every commit.
# When you see `BASELINE STALE`, delete the line. Nothing else maintains this file.
#
# Enumerated by node id, not by file, deliberately. Every file named below also holds
# tests that pass, so deselecting the file instead would hide those -- and would hide a
# new failure in it, which is the whole thing this file exists to prevent.
#
# A line belongs here only when the cause is this machine's installed packages rather
# than this repo, and only with the command that clears it. A real failure goes in a
# fix, not in here.
